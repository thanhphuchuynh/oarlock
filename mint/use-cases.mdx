A support engineer needs a shell on a machine in someone else's building. The usual answers put a listener on that machine. Oarlock does not.

## What it is not for

- An L3 overlay for the whole fleet. That is Tailscale or OpenZiti.
- Device management, enrollment, or OTA. It opens shells.
- A product that hides the cost: the gateway reads the plaintext. If that is unacceptable, mode A passthrough exists and is unrecorded on purpose.
