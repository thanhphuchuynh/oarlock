Use cases

The machine you cannot dial

A support engineer needs a shell on hardware in someone else’s building. Oarlock is what you run when inbound SSH is not a thing you can ask for.

The problem

treadmill-4821 is on a customer LAN

It is behind NAT, often on a cellular APN, often asleep. It has no public address. You cannot put a listener, a host key, or an open port on it.

What fails

Inbound SSH never arrives

ssh: connect to host treadmill-4821 port 22: Connection timed out

A VPN overlay is a fleet on a network. You wanted one shell, on one device, for one person, recorded.

What Oarlock does

The device only ever dials out

The agent opens TLS to :443. The gateway is the SSH server. Nothing new listens on the internet, and nothing at all listens on the device.

The session

A real ssh prompt, in the plaintext

ssh treadmill-4821@gw · this session is recorded

Because the gateway terminates SSH, every session can be recorded, and a failure is a named reason — not “connection closed”.

While it is open

Access can be withdrawn now

Authorisation is re-checked while the shell is live. A departed operator does not keep a session until they hang up. The device never held their credential.

Where this is the job

Four times you actually open it

Not a mesh. One session, one device, one person, with a recording you can stand behind.
